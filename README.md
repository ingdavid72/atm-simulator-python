# Simulador de Cajero Automático en Python 🏦

Proyecto desarrollado para la materia de **Fundamentos de Programación**.

## 🚀 Funcionalidades
- Consulta de saldo en tiempo real.
- Depósito y retiro de dinero con validación de montos.
- Historial de transacciones durante la sesión.
- Manejo de excepciones (`try/except`) para evitar errores de ejecución.

## 🎯 Problema que resuelve
Este proyecto aborda la necesidad de simular un sistema bancario automatizado básico, resolviendo dos retos principales:
1. **Para el usuario:** Permite la gestión autónoma de fondos (consultas, depósitos y retiros) garantizando la integridad de su saldo mediante la validación estricta de cada operación.
2. **Lógica de software:** Previene fallos en el sistema mediante el control de operaciones no válidas (fondos insuficientes o montos negativos) y el manejo de errores ante entradas incorrectas del usuario.

## 🛠️ Tecnologías utilizadas
- Python 3.
